
# Hypertension Stage Predictor

A machine learning web application that predicts systolic blood pressure (SBP), diastolic blood pressure (DBP) categories, and hypertension classification using patient demographic, lifestyle, and clinical data.

Features
- SBP and DBP category prediction.
- Hypertension classification.
- Interactive patient input interface.

 Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit

 Deployment
Built with Streamlit and deployed using Streamlit Community Cloud.
